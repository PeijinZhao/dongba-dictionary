01

为什么音标看起来"乱码"

原始数据来源把音标记录成了一段没有完整渲染的 LaTeX 数学公式片段， 例如 \$a^{33}\$，本来应该显示成 a³³。 网页现在会自动做转换：去掉 \$ ... \$ 包裹符号、 把 ^{33} 这种调值数字转成上标、把 ^{h} 转成送气符号 ʰ。 极少数条目（带 ⚠︎ 标记）用了 \eta \xi \mathcal{S} \angle 这类数学符号宏，大概率是原始资料 用了特殊语音字体、被转码搞乱了，具体对应哪个国际音标符号无法仅凭文本100%确认， 所以网页里会保留方括号 + 原宏名（例如 t[xi?]）原样展示，并不会替你瞎猜， 如需精确核对建议查阅原始参考文献（如李霖灿《纳西族象形文字字典》）。

02

调值数字是什么

数字写在音节右上角，表示这个音节的声调（音高），采用语言学里常见的"五度标调法"： 数字越大代表音高越高。常见组合：

调值大致音高走向
⁵⁵高平调（从高到高，持平）
³³中平调（从中到中，持平）
³¹中降调（从中往低下降）
¹³ / ¹⁵低升调（从低往上升）
03

常见符号对照

下面只列出这套词典里实际出现过的符号，不是完整的国际音标表。

符号类别说明
ʰ送气标记写在辅音右上角，表示送气，如 kʰ、tsʰ
ɯ元音不圆唇后高元音，类似汉语拼音 "e" 在某些方言里的发音
ɑ元音后低元音，比普通话 "a" 更靠后
ə / ǝ元音中央元音（schwa），类似轻读的"鹅"音
ɛ元音前中低元音，类似英语 bed 里的 e
ȵ辅音硬腭鼻音，类似汉语拼音 "ni" 里的 n 音色
ŋ辅音软腭鼻音，类似英语 sing 结尾的 ng
ɡ辅音软腭浊塞音，类似英语 "go" 的 g
ɣ辅音软腭浊擦音，比 g 更"擦"一些
ʂ / ʐ辅音卷舌擦音，类似汉语拼音 sh / r 的音色
ʦ / ʣ辅音齿龈塞擦音（清/浊），类似汉语拼音 z / c
ʨ / ʥ辅音齿龈-硬腭塞擦音，类似汉语拼音 j / q 的音色
ɿ / ʅ元音舌尖元音，类似汉语拼音 zi / shi 里那个不太响的元音
ç辅音硬腭清擦音，类似德语 ich 里的 ch
