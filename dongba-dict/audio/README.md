# 录音存放说明

把真人录音的 mp3 文件放在这个文件夹里，文件名要跟词典里的 `unicode` 字段对应，例如：

```
audio/U+E000.mp3   <- 对应 dongba.json 里 unicode 字段为 "U+E000.svg" 的那个字
audio/U+E0A1.mp3
```

网页会自动检测：有对应文件名的录音就优先播放；没有的话，会用浏览器自带语音引擎
近似拟读罗马转写名称，并在界面上提示"非纳西语真实发音"。

录制建议：
- 找东巴文化研究院、纳西族东巴传承人，或熟悉纳西语的母语者按"罗马转写名称"逐字朗读。
- 格式用 mp3 即可，单字录音通常 1～3 秒，不需要很长。
- 如果暂时没法大规模录制，可以先挑常用/优先级高的几十个字试录，验证流程没问题后再批量补充。
